# NAI 통합 연결 1.0.0

**화면 확장 하나 + 서버 플러그인 하나**로 여러 이미지 생성 서비스를 전환합니다. 사이트를 바꿀 때마다 전용 서버 플러그인을 추가·교체할 필요가 없습니다.

지원 연결:

| 서비스 | 입력 정보 | 처리 방식 |
| --- | --- | --- |
| Shared- | 사이트 아이디·비밀번호 | 사이트 로그인 후 계정에 등록된 키 사용 |
| Sakura- | 사이트에서 받은 키 | relay.tenshimomone.com 연결 |
| 다른 NovelAI 호환 서버 | API 기본 주소·키 | 호환 요청 전달 |

모든 웹사이트의 API가 자동 지원되는 것은 아닙니다. 자체 로그인·생성 규격을 쓰는 새로운 사이트는 통합 플러그인에 해당 규격을 추가해야 합니다. 일반 NovelAI 호환 서버는 화면에서 주소와 키만 추가하면 됩니다.

## 설치 — 최초 한 번

1. SillyTavern 서버를 종료합니다.
2. `extension` 안 파일을 `SillyTavern/data/default-user/extensions/nai-connection-hub/`에 복사합니다. 사용자 지정 데이터 폴더나 다중 사용자라면 실제 사용자 확장 폴더를 사용하세요.
3. `server` 안 파일을 `SillyTavern/plugins/nai-connection-hub/`에 복사합니다. 최종 위치가 `plugins/nai-connection-hub/index.js`와 `package.json`인지 확인하세요.
4. 기존 `config.yaml`의 `enableServerPlugins`를 `true`로 설정합니다.
5. 서버를 재시작하고 브라우저를 새로고침합니다.
6. 확장 설정 → **000 NAI 통합 연결**을 엽니다.

Node.js 20 이상이 필요합니다. 추가 npm 패키지는 필요하지 않습니다. 서버 플러그인은 SillyTavern이 실제로 실행되는 컴퓨터에 설치합니다.

## 기존 개별 확장에서 이동

- 기존 SharedNAI·Sakura의 로그인 파일을 자동으로 가져오지 않습니다. 처음 한 번은 통합 화면에서 각 서비스를 연결하세요.
- 통합 연결을 활성화하면 기존 SharedNAI·Sakura 화면 확장의 연결 체크를 끕니다.
- 정상 생성 확인 후 기존 개별 화면 확장과 `plugins/sharednai-bridge`, `plugins/sakura-nai-bridge`는 필요 없으면 제거할 수 있습니다. 통합 서버 `plugins/nai-connection-hub`만 남기면 됩니다.
- 기존 AutoPic 자체는 유지합니다. AutoPic의 다른 기능을 사용하는 서버 플러그인은 필요 여부에 따라 유지하세요.
- 확장 이름의 `000`과 로딩 순서는 AutoPic 요청 변환에 사용하므로 변경하지 마세요.

## 연결을 추가하고 전환하기

1. **연결 추가 또는 갱신**에서 서비스를 고릅니다.
2. SharedNAI는 계정 아이디·비밀번호, Sakura는 사이트 키를 입력합니다.
3. 다른 서버는 **다른 NovelAI 호환 서버**를 고르고 API 기본 주소·연결 이름·키를 입력합니다.
4. **새 연결 저장**을 켜고 **추가하고 연결**을 누릅니다.
5. 다른 서비스를 추가할 때도 같은 과정을 반복합니다.
6. 이후 **등록된 연결 → 연결 전환**만 누르면 됩니다. 이미 등록된 인증 정보를 재입력할 필요는 없습니다.

기본 서비스는 서비스별 한 계정을 보관합니다. 같은 서비스를 다시 등록하면 해당 인증 정보를 갱신합니다. 사용자 지정 서버는 API 주소별로 구분하며 동일 주소를 등록하면 기존 연결을 갱신합니다. 생성 중 전환하면 진행 중인 요청은 원래 서버에서 마무리되고 다음 요청부터 새 연결을 사용합니다.

**현재 연결 해제·삭제**는 현재 연결만 삭제합니다. 다른 등록된 연결은 유지합니다. 등록된 연결을 전환한 뒤 삭제하면 개별 정리할 수 있습니다.

## 이미지 생성 설정

- 기본 Image Generation: 소스를 **NovelAI**로 선택합니다.
- AutoPic: **ST Image Generation · 기존 방식**, **AutoPic · V4.5 Full**, **AutoPic · V5 Full**을 지원합니다.
- 기존 방식에서 AutoPic 캐릭터/참조 기능을 쓰려면 AutoPic의 서버 플러그인 기능을 켭니다. 실제 이미지 요청은 통합 서버가 처리합니다.
- 모델·프롬프트·크기·캐릭터 설정은 기존 이미지 생성 확장에서 선택합니다. 통합 연결 자체에는 이미지 생성 버튼이 없습니다.
- 공식 NovelAI 키 입력란에 사이트 키를 넣지 않아도 됩니다.

다른 확장은 ST의 동일한 NovelAI/AutoPic 이미지 요청 경로를 fetch로 사용할 때 연결됩니다. 직접 외부 서버를 호출하는 확장이나 독자적인 요청 규격은 별도 연동이 필요할 수 있습니다.

## 사용자 지정 서버의 호환 조건

일반 웹페이지 주소가 아니라 서비스 제공자가 안내하는 **HTTPS API 기본 주소**를 입력하세요. 예를 들어 기본 주소가 `https://api.example.com/nai`라면 다음 경로가 제공되어야 합니다.

- `GET /nai/user/subscription` — 키/구독 정보
- `POST /nai/ai/generate-image` — NovelAI 형식의 이미지 생성
- `POST /nai/ai/encode-vibe` — Vibe를 사용하는 경우

인증은 `Authorization: Bearer 키`입니다. 키 조회는 NovelAI의 `tier`, `active` 필드를 포함하는 구독 응답이어야 합니다. 이미지는 PNG 또는 PNG를 포함한 ZIP, 또는 `images[].image`에 base64/바이트 배열이 담긴 JSON을 지원합니다. 다른 응답 규격은 별도 어댑터가 필요합니다.

공개 인터넷의 HTTPS 서버만 지원합니다. HTTP, localhost, 사설 IP 주소는 지원하지 않습니다. 인증 키를 포함한 요청은 다른 주소로 리다이렉트하지 않습니다. 사용자 지정 주소는 입력한 서버로 키가 전송되므로 제공자가 안내한 주소를 사용하세요.

## 인증 정보 저장

- 비밀번호는 로그인 요청에만 사용하고 저장하지 않습니다.
- 저장을 켠 연결의 키/로그인 토큰은 사용자 데이터 폴더의 `.nai-connection-hub.json`에 저장합니다. 파일은 암호화되지 않으므로 공개 저장소나 배포 ZIP에 포함하지 마세요.
- 저장을 끄면 현재 서버가 실행되는 동안만 해당 연결을 유지합니다. 다른 저장된 연결은 삭제하지 않습니다.
- 재시작 후 마지막으로 사용한 저장 연결을 복원합니다. 마지막 연결이 저장하지 않은 연결이었다면 자동 선택하지 않고 등록된 연결에서 선택하도록 합니다.
- 토큰이 만료된 연결만 제거하며, 다른 연결과 다른 사용자의 키는 유지합니다.
- 브라우저의 확장 설정이나 API 응답에 키/로그인 토큰을 포함하지 않습니다.

## 제한과 오류

텍스트→이미지 한 장씩 지원합니다. 자동 업스케일·img2img·인페인팅은 지원하지 않습니다. 해상도는 64의 배수, 한 변 최대 2048px, 총 3,145,728픽셀 이하입니다. V5에서는 Vibe·Director Reference·SMEA·Decrisper·Variety Boost를 지원하지 않습니다. V4.5의 Vibe와 Director Reference는 동시에 사용하지 마세요.

같은 서버·키의 동시 생성은 차단하며 자동 재시도하지 않습니다. 통신이 끊긴 경우 생성이 처리됐을 수 있으니 사이트에서 결과를 확인한 뒤 재시도하세요. 401은 인증 갱신 필요, 429는 사용량/동시 생성 제한, 502 등은 서버 연결이나 응답 오류를 확인하세요.

새 서비스를 추가할 때 인증이 실패하면 기존 연결은 유지됩니다. 사용자 지정 서버가 호환 규격을 제공하지 않는다면 주소를 바꿔도 연결되지 않을 수 있습니다.

## 배포

- 화면 확장 ZIP의 `extension` **안 파일**을 GitHub 저장소 최상위에 올립니다. `manifest.json`이 최상위에 있어야 합니다.
- 서버 ZIP은 직접 공유하거나 별도 저장소로 올려도 됩니다. 설치할 서버 플러그인은 이것 하나입니다.
- 사이트를 추가로 사용할 때마다 서버 ZIP을 교체하지 않습니다. 지원하지 않는 새로운 API 규격이나 버그 수정에 대해서만 업데이트가 필요합니다.

## 검증

2026-11-01 기준 서비스별 인증·전환, 서버 재시작 후 복원, 사용자 격리, 키 노출 방지, 생성 중 서비스 변경, 1MB 초과 SharedNAI 이미지, Vibe 정규화, AutoPic 전달, 네트워크 주소 검사를 자동 테스트했습니다. 로컬 브라우저에서 320/390/768/1366px 화면의 연결 추가·전환·삭제·복원을 확인했습니다. 실제 HTTPS 연결은 두 기본 서비스의 인증 없는 조회가 401을 반환하는 것으로 확인했습니다.

실제 사용자 계정 로그인이나 유료 이미지 생성은 수행하지 않았습니다. 설치 후 인증 확인 → 이미지 한 장 생성 순서로 확인하세요.
